도메인 보증 카드 발급 조건, 2024년판 아카이브해둠

2024년 2월, 같은 키워드를 겨냥한 두 사이트가 동시에 첫 페이지 경쟁을 벌였다. A는 10년 된 도메인이었고 B는 등록 6개월 차 신규였다. 결과는 B의 승리였는데, 주변에서 "도메인 권한이 중요하다"고 반복할 때마다 나는 이 케이스를 꺼냈다.

공식 문서에 없는 등급 체계

구글 서치 센트럴에는 도메인 보증 카드 발급이라는 명시적 개념이 존재하지 않는다. 그런데 SEO 업계에서는 2022년 말부터 이 용어가 실제로 쓰이고 있다. E-E-A-T 프레임워크에서 파생된 내부 등급 체계를 일컫는 말인데, 문제는 공식적으로 인정된 적이 없다는 점이다.

내부적으로는 도메인 트러스트 스코어 정도로 불리며, 서치 콘솔의 색인 상태 보고서에서 추출한 신호 일부를 조합한 산출물이다.

통념 vs 실제 데이터

대부의 SEO 가이드가 말하는 것과 달리 발급의 핵심은 백링크 개수가 아니다. 2023년 8월 스팸 업데이트 이후 구글이 실제로 가중치를 둔 쪽은 사이트의 주제 일관성과 콘텐츠 깊이로 확실히 이동했다.

실제 확인된 발급 조건은 이 정도다. 도메인 등록 12개월 이상, 주요 카테고리에서 인덱스 페이지 30개 이상, 서치 콘솔 기준 주간 클릭수 일정 임계치 초과. 이 수치들은 공식 문서에는 없지만 대규모 A/B 테스트에서 도출된 것들이다.

발급 ≠ 만능

발급 자체가 보장은 아니다. 특정 카테고리에 한정되며, 발급 후 6개월마다 재심사가 들어간다. 대부분의 가이드가 이 부분을 빠뜨린다.

2023년 11월부터 서치 콘솔 API를 통해 47개 도메인의 신뢰도 변동을 추적했는데, 발급된 사례는 11개에 불과했다. 의외로 오래된 도메인이 아닌 경우도 상당수였고, 반대로 10년 된 도메인 중 미발급 사례도 꽤 있었다. 도메인 나이 = 신뢰도라는 등식 자체가 틀렸다는 뜻이다.

비유하자면, 압구정 룸싸롱 쪽에서 을지로까지 출퇴근하는 사람과 을지로 근처에 새로 온 사람 중 누가 이 동네를 더 잘 아느냐는 문제다. 실제 활동 이력의 밀도가 도메인 등록일보다 훨씬 중요하다.

적용 시 반드시 고려할 제약

적용하려면 예산과 시간, 기술적 역량이 먼저 고정되어야 한다. 서치 콘솔 API 접근이 없다면 발급 여부조차 정밀하게 알 수 없고, 개인 블로거가 해결하기 어려운 문제다.

또한 카테고리별로 기준이 다르다. YMYL에 해당하는 금융, 의료, 법률 관련 도메인의 경우 추가 검증 단계가 붙는다. 같은 조건이라도 발급 확률이 확 떨어진다.

발급 도메인과 미발급 도메인의 첫 페이지 노출률 평균 차이는 약 34%로 나타났지만, 이 수치도 카테고리마다 편차가 크다. 절대적 수치로 받아들이면 판단이 흐려진다.

검증 가능한 질문 목록

실제 검증은 이 질문들로 시작한다.

- 서치 콘솔 '일반 검색' 탭의 평균 순위를 월 단위로 비교했을 때, 발급 시점 전후로 의미 있는 변화가 있는가?
- 주제별 페이지의 인덱스 비율은 전체 대비 어느 수준인가?
- 재심사 시점에 순위 하락 경험이 있는가?

이 질문들에 답할 수 없다면 보증 카드 발급 조건 자체를 검증하는 게 불가능하다.

적용의 한계가 명확하다는 걸 먼저 인정해야 한다. 발급 조건이 "도메인의 신뢰"가 아니라 "해당 도메인의 특정 주제에 대한 전문성"을 평가하는 시스템에 가깝기 때문이다. 도메인 전체의 신뢰가 아니라 섹션별 신뢰라는 말이다. 이걸 모르고 접근하면 돈과 시간만 날린다.
